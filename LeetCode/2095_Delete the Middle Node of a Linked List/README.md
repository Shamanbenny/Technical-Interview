# Delete the Middle Node of a Linked List

Given the `head` of a linked list, delete the middle node and return the head of the modified list. For a list of size `n`, the middle node is the `floor(n / 2)`th node from the start using 0-based indexing.

### Examples

- Input: `head = [1,3,4,7,1,2,6]`; Output: `[1,3,4,1,2,6]`
- Input: `head = [1,2,3,4]`; Output: `[1,2,4]`
- Input: `head = [2,1]`; Output: `[2]`

### Constraints

- The number of nodes is in `[1, 10^5]`.
- `1 <= Node.val <= 10^5`
