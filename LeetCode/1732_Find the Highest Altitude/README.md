# Find the Highest Altitude

A biker starts at altitude `0`. Given `gain`, where `gain[i]` is the net altitude gain between points `i` and `i + 1`, return the highest altitude reached.

### Examples

- Input: `gain = [-5,1,5,0,-7]`; Output: `1`
- Input: `gain = [-4,-3,-2,-1,4,3,2]`; Output: `0`

### Constraints

- `n == gain.length`
- `1 <= n <= 100`
- `-100 <= gain[i] <= 100`

Difficulty: Easy
