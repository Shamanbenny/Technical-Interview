# Equal Row and Column Pairs

Given a 0-indexed `n x n` integer matrix `grid`, return the number of pairs `(r_i, c_j)` such that row `r_i` and column `c_j` contain the same elements in the same order.

### Examples

- Input: `grid = [[3,2,1],[1,7,6],[2,7,7]]`; Output: `1`
- Input: `grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]`; Output: `3`

### Constraints

- `n == grid.length == grid[i].length`
- `1 <= n <= 200`
- `1 <= grid[i][j] <= 10^5`
