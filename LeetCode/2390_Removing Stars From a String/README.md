# Removing Stars From a String

Given a string `s` containing stars, choose a star and remove the closest non-star character to its left along with the star. Return the string after all stars have been removed. The operation is always possible and the result is unique.

### Examples

- Input: `s = "leet**cod*e"`; Output: `"lecoe"`
- Input: `s = "erase*****"`; Output: `""`

### Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters and stars.
